# Sample dataset

Synthetic, generated by `scripts/make_sample_dataset.py` (seed 20261024): drawn frames, invented detections, the synthetic sonde and weather generators. `python -m app.seed` (or `make seed`) loads it into an empty database, shifting every timestamp so the newest row is now. Nothing here is real footage or a real reading.

- `detection_events.jsonl`: 320 rows
- `saved_frames.jsonl`: 40 rows
- `sensor_readings.jsonl`: 504 rows
- `weather_readings.jsonl`: 126 rows
- `alerts.jsonl`: 3 rows
- `frames/`: 40 JPEG frames with COCO sidecars
